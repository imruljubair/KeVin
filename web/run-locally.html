Make the prompt your own.

Edit prefill text, load supported GGUF models, and generate beyond the web demo’s five recorded tokens. Your model runs on your computer.

You’ll need

Python 3.10+, Git, CMake 3.20+, a C++17 compiler, and an internet connection for the initial setup and model download. The default context is 128 tokens.

1. Install the build tools

macOS

Install the Xcode command line tools:

xcode-select --install

Install Python 3 and CMake from their official installers, or use Homebrew if you already have it:

brew install python cmake

Ubuntu / Debian, or Windows with WSL2 Ubuntu

sudo apt update
sudo apt install python3 git cmake build-essential

On Windows, run the remaining commands inside your WSL2 Ubuntu terminal.

2. Get KeVin

Clone the repository, or use GitHub Desktop’s Clone repository and open a terminal in that folder.

git clone https://github.com/imruljubair/KeVin.git
cd KeVin

View the source on GitHub ↗

3. Build the inference engine

python3 scripts/setup.py

This downloads the pinned llama.cpp source and builds KeVin’s inspection engine. It can take a few minutes. There are no pip or npm dependencies.

4. Start KeVin

python3 -m kevin

Open http://127.0.0.1:8765/. Keep the terminal open while using KeVin. Stop it with Ctrl+C.

If that port is occupied, select an available port automatically:

python3 -m kevin --port 0

5. Load a model and explore

Choose SmolLM2 135M in the model picker, then click Load model. Enter your own prompt and click Prefill. Generate tokens one at a time or use Play.

Other supported GGUF models are available in the picker. Downloads are stored locally and reused. Generation is bounded by the model context, available memory, and end-of-sequence tokens.

If something doesn’t start

  • Missing compiler or CMake: finish step 1, open a new terminal, then rerun setup.
  • Engine is not built: run python3 scripts/setup.py from the repository folder.
  • Port already in use: use --port 0 and open the address printed in the terminal.
  • A model fails to load: start with the recommended SmolLM2 135M model and check the terminal or engine.log.
