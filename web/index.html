Meet KeVin.

Pronounced “Kevin.” An inference-only explorer of a real pretrained model’s attention and KV cache, inspired by littleLLAMA.

Read the picture

The prompt is processed together in prefill. Each decode column processes one generated token. Previous keys and values are reused; only the new entries are appended.

Every color comes from inference

Keys and queries are captured after rotary position encoding. Cache heatmaps use the actual F16 cache operands. Attention colors are probabilities from the model’s softmax. Flash Attention is disabled for inspection.

A proxy for a large matrix

Each block retains actual cells from its four corners. Corner depths follow the square roots of the real row and column counts. Original indices label the retained cells; shaded bands with ellipses stand for omitted ranges. The proxy grows wider or taller with the matrix, with a bounded prefill proxy followed by all generated entries. No cells are averaged.

Fading toward the hidden center

Retained cells gradually fade as they approach an omitted range. A shaded gap has no displayed numerical value. Click a cell to inspect its original coordinates and captured precision. Numbers controls labels without changing the proxy, and labels appear when zoomed in enough to read.

The same attention layout

Kᵀ sits beside A, and V beside VA. Caches appear below the divider. New cache entries use the same simple matrix outline. Click projection, A, or VA cells to trace their math. Blue orthogonal connectors follow littleLLAMA’s style: solid lines connect displayed operands, dashed lines connect omitted ranges. Compact cache uses one shared Kᵀ/V operand and cache snapshot; each query still attends only to its own visible prefix.

X and Q stay visible. Weights and K/V expands the real selected-head Wq/Wk/Wv weights and K/V projections. Orange weight blocks are shared across steps and use the same corner shading. Q/K apply RoPE, and K/V are rounded by the F16 cache write. These calculations run in the model whether the bracket is open or closed. Prefill proxy ranges stay fixed; every generated token is appended visibly. Non-compact decode columns show only added K/V rows and columns. Click a matrix to zoom smoothly.

Generation uses greedy decoding. Query heads can share a KV head; switching heads preserves the inference timeline. The cache indicator reports logical tensor bytes, excluding allocation padding.
